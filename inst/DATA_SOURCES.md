# Bundled functional databases

The `plankannot` package distributes four curated functional databases:

- `db/copepoda.rds`
- `db/habs.rds`
- `db/mixoplankton.rds`
- `db/phytoplankton.rds`

These databases were assembled by Roberta Piredda and Mariangela Santorsola for
use with the `plankannot` package.

## Scope and provenance

The package authors are responsible for the curation and organization of
these bundled database files. Before the first public release, the authors
should retain and make available the underlying source bibliography,
data-selection criteria, taxonomic naming references, and database version
or preparation dates for each resource.

If any records or annotations incorporate material from third-party
publications or databases, the corresponding sources and applicable
redistribution terms must be documented here. The package-level MIT license
does not override third-party rights or licenses.

## Database-specific documentation

For each database, the release documentation should record:

1. Database name and version or preparation date.
2. Authors and contributors.
3. Source publications or datasets, where applicable.
4. Inclusion and exclusion criteria.
5. Meaning of the columns, including `Species_Name`.
6. Any normalization, synonym handling, or other curation steps.
7. Applicable data license or permission for redistribution.
